# Roster2023 (synthetic site roster, year three)

`Roster2022` plus 20 newly enrolled subjects, minus 2 who withdrew. See
[`Roster2021`](https://mjfrigaard.github.io/dfdiffs/reference/Roster2021.md)
for column details.

## Usage

``` r
Roster2023
```

## Format

A data frame with 255 rows and 11 variables (see
[`Roster2021`](https://mjfrigaard.github.io/dfdiffs/reference/Roster2021.md))
