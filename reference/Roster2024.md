# Roster2024 (synthetic site roster, year four)

`Roster2023` plus 20 newly enrolled subjects, no withdrawals. See
[`Roster2021`](https://mjfrigaard.github.io/dfdiffs/reference/Roster2021.md)
for column details.

## Usage

``` r
Roster2024
```

## Format

A data frame with 275 rows and 11 variables (see
[`Roster2021`](https://mjfrigaard.github.io/dfdiffs/reference/Roster2021.md))
