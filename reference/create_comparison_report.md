# Create comparison report

Create comparison report

## Usage

``` r
create_comparison_report(
  compare,
  base,
  by = NULL,
  by_col = NULL,
  cols = NULL,
  file
)
```

## Arguments

- compare:

  compare df

- base:

  base df

- by:

  keys or joining column

- by_col:

  column name for joining column

- cols:

  columns to compare

- file:

  export file (with path)

## Value

xlsx workbook
