# Create comparison report

Create comparison report

## Usage

``` r
create_comparison_report(
  compare,
  base,
  by = NULL,
  by_col = NULL,
  cols = NULL,
  file
)
```

## Arguments

- compare:

  compare df

- base:

  base df

- by:

  keys or joining bs4Dash::column

- by_col:

  bs4Dash::column name for joining bs4Dash::column

- cols:

  columns to compare

- file:

  export file (with path)

## Value

xlsx workbook
