# Roster2022 (synthetic site roster, year two)

`Roster2021` plus 40 newly enrolled subjects, minus 3 who withdrew. See
[`Roster2021`](https://mjfrigaard.github.io/dfdiffs/reference/Roster2021.md)
for column details.

## Usage

``` r
Roster2022
```

## Format

A data frame with 237 rows and 11 variables (see
[`Roster2021`](https://mjfrigaard.github.io/dfdiffs/reference/Roster2021.md))
