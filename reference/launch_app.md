# Launch the dfdiffs app

Standalone launcher for the production `dfdiffs` comparison app (upload,
select, and compare two datasets)

## Usage

``` r
launch_app(options = list())
```

## Arguments

- options:

  A list of Shiny options (e.g., `list(test.mode = TRUE)`)

## Value

A `shiny.appobj`

## Examples

``` r
if (FALSE) { # \dontrun{
launch_app()
} # }
```
