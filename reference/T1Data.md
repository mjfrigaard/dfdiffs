# T1Data (simulated 'time-point 1' data for checking 'new data')

A dataset containing six rows and seven columns. The variables are as
follows:

## Usage

``` r
T1Data
```

## Format

A data frame with 6 rows and 7 variables:

- subject:

  A character ID variable ("A", "B", "C", "D")

- record:

  A numeric record ID (1-6)

- start_date:

  a beginning date (from 2022-01-25 to 2022-01-30)

- mid_date:

  a middle date (from 2022-03-15 to 2022-03-20)

- end_date:

  a last date (from 2022-03-25 to 2022-03-31)

- text_var:

  a variable containing random text

- factor_var:

  a categorical variable formatted as a factor
